# Boundaries

The active neural demo is the selected frozen grouped_1 model. It is not the separate all-animal checkpoint, which selected zero neural correction. Choosing this existing active checkpoint demonstrates the proposed neural architecture; it does not change the manuscript's overall negative/weak superiority conclusions.

- Source age is5 weeks; no arbitrary new mouse RNA upload or dynamic source-age handoff.
- Only nine declared query ages and increasing schedules. No backward cycles or RNA re-entry.
- Genotype/type/time are observational conditions, not causal intervention actions.
- Measured-age GT is animal-disjoint at ages present in training. This deployment is not a week24/30 forward-age holdout. Those distinct historical fold scores stay labelled in the evidence table.
- Intermediate ages have no measured GT. Custom schedule outputs are unverified predictions.
- Marginal NB sampling does not fit full biological coexpression or forecast total RNA content. Generated panel counts exclude other genes.
-16 program definitions remain exact. Absent markers are not imputed; the primary mitochondrial program is unavailable. Sensitivity-fit predictions are not substituted.
- Stored residual-PC reference coordinates use the same encoder but are not a newly fitted embedding of live RNA samples.
- Mouse populations are destructive cross-sectional observations. No tracked cell lineage, tissue abundance, protein function or human temporal prediction is claimed.
- Generated nuclei are technical/model draws, not biological experimental units. No calibrated new-animal intervals or independently significant pathway discoveries are asserted.
- Changing selected genes changes only the view/export; inference still produces all2,000 genes. Node-specific effect metrics compare all2,000 genes and only genuine measured GT.
